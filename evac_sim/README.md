# Расчётное ядро evac-sim v0.3.0

Java-модуль общего приложения. Основные команды сборки и запуска приведены в [корневом README](../README.md); приложение запускается из `server/target/evacuation-sim-0.3.0.jar` после корневой сборки.

Основные пакеты:

- `model` — геометрия и атрибуты помещений/проходов.
- `parser` — проверка XML и разбор SVG через Apache Batik.
- `graph` — исходное представление графа для консольного просмотра.
- `simulation` — общий контракт `EvacuationNetwork`, событийный `NetworkSimulationService` и воспроизводимый `NetworkResult` с временными сегментами людей.
- `web` — исторический одноэтажный HTTP-адаптер `/api/analyze`, сохранённый для совместимости.

`server` преобразует размеченные и обычные SVG в одну сеть, передаёт её движку, сохраняет результат в SQLite и отдаёт браузеру. Сборка нескольких этажей и авторизация находятся в `server`; интерфейс приложения — в `web`, а прежние страницы в ресурсах этого модуля остаются исторической демонстрацией.

Для проверки только ядра:

```bash
mvn -B -f evac_sim/pom.xml clean verify
```

Дополнительный артефакт `target/evac-sim-0.3.0-standalone.jar` сохраняет консольный просмотр SVG и старый режим `--serve`. Этот адаптер рассчитывает один этаж. Основной многоэтажный сценарий запускайте через сервер из корня проекта.

Формат предметной разметки: [format_spec.md](format_spec.md). Границы физической модели и следующие этапы: [PROJECT_STATUS.md](../docs/PROJECT_STATUS.md), [ROADMAP.md](../docs/ROADMAP.md).
